# AI 学习路线推荐

> 来源：技术部 01-战略与规划《2026-2027社团一年预期的发展规划》第七章，2026-10
> 以下三条路线属于**个人长期型社团活动**：社员可自选一条，在社团内找学习搭子组队学习，部门提供答疑与支持。不纳入技术部统一活动。

---

## 路线一：自顶向下（应用 → 原理）

- **教程**：[hello-agents 教程](https://hello-agents.datawhale.cc/#/)
- **路径**：Agent 应用 → 大模型 / Transformer → PyTorch 逐层下沉
- **适合**：先做起来再补原理，从应用切入逐步深入底层

## 路线二：AI Engineering from Scratch

- **教程**：[aieng-zh.cn](https://aieng-zh.cn/)
- **路径**：数学 → ML → DL → LLM → Agent（自底向上系统课）
- **适合**：希望系统打基础，从数学基础一路建到 Agent 应用

## 路线三：LAMDA Lab-RoadMap

- **教程**：[GitHub 路线](https://github.com/LAMDA-NeSy/Lab-RoadMap)
- **路径**：AIMA 教材 + Python 基础的学院派路线
- **适合**：偏好学术路线，从经典教材出发打好 AI 理论基础

---

### 使用建议

1. **任选一条**深入，不要同时铺开多条。
2. 在社团内找学习搭子，组队打卡、互相答疑。
3. 技术部提供答疑支持，但不统一排课。
4. 学完后可在社团内做一次分享，把成果沉淀为教学资料。
