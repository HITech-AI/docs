# HITech-AI Docs

> **"智启新航"AI 研学社 · 文档库** · 沉淀知识，让学习有迹可循

本仓库是社团的**知识库**，承载技术科普、教学资料与活动归档，供成员查阅与持续完善。

## 目录结构

```
docs/
├── 科普/            # 面向全社的 AI 科普文章
├── 教学/            # 活动与课程教学资料、工作坊讲义
├── 学习路线/        # 推荐的学习路线与外部优质资源索引
├── 活动归档/        # 每场活动的记录与产出
└── 部门资料/        # 各部门内部资料（战略、规划、问卷等）
```

> 新内容**加目录**，不新建仓库（仓库固定、目录扩展原则）。

## 文档规范

- 统一使用 **Markdown** 编写，文件名清晰、避免含空格的命名。
- 每篇文档建议包含：**背景/用途 → 正文 → 参考链接**。
- 科普与教学类文档尽量**面向零基础**读者，配可操作的示例。

## 如何贡献

1. 阅读 [CONTRIBUTING](https://github.com/HITech-AI/HITech-AI/blob/main/CONTRIBUTING.md)。
2. Fork 本仓库，在对应目录新增或修订文档。
3. 提交 PR，注明改动内容与目的。
