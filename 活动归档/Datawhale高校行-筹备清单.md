## 一、前期筹备（活动前 2–3 周）

- [ ] 敲定时间、地点、报名方式（当前通知里均为「待定」，需第一时间落实）
- [ ] 与 DataWhale 对接：教学资源、证书模板、周边物料数量与寄送时间（确认证书发放方式与数量）
- [ ] 确定分享嘉宾（技术部员）与分享大纲（AI 通识 + Agent 使用入门）
- [ ] 准备 Agent 搭建演示（现场可跑通的 demo，提前彩排）
- [ ] 设计动手实践题目（一个高频场景 AI 小作品，给零基础同学可完成的路径）
- [ ] 申请教室/场地（容纳人数、投影、网络、电源）
- [ ] 制定现场分工（主持、分享、助教、签到、摄影、后勤）
- [ ] 搭建报名表单（收集姓名 / 校区 / 联系方式 / 是否零基础）
- [ ] 建立活动咨询群并生成二维码（用于通知答疑与报名）

## 二、宣传招募（活动前 1–2 周）

- [x] 海报定稿（已完成，见宣传部 10-荣誉与成果）
- [x] 活动通知文案发布（已完成，见宣传部 02-活动方案）
- [ ] 通过公众号 / 社团群 / 朋友圈发布通知（附报名链接与咨询群二维码）
- [ ] 运营咨询群（答疑、引导报名、收集意向）
- [ ] 统计报名人数（必要时调整场地规模）
- [ ] 报名截止前 2–3 天群内提醒（倒计时，避免遗忘）

## 三、现场执行（活动当天）

- [ ] 提前 1 小时到场，调试投影、麦克风、网络（准备备用网络/PPT）
- [ ] 签到台：签到、引导入座（签到表或二维码）
- [ ] 开场主持与活动介绍（介绍 DataWhale 与社团）
- [ ] 技术部员分享（AI 通识 + Agent 入门）
- [ ] Agent 搭建现场演示（展示创建仓库、生成 README、解报错）
- [ ] 动手实践环节（助教巡场答疑，保证零基础同学跟上）
- [ ] 收集小作品提交（GitHub 仓库或统一表单）
- [ ] 颁发证书、发放周边（DataWhale 证书 + 社团周边）
- [ ] 合影与现场摄影记录（为回顾推送备素材）

## 四、收尾复盘（活动后 1 周内）

- [ ] 发送活动反馈问卷（收集体验改进建议）
- [ ] 整理提交的小作品清单（可作为后续社团案例展示）
- [ ] 跟进 DataWhale 证书发放（确认证书到同学手中）
- [ ] 撰写活动回顾推送（含照片、作品、同学反馈）
- [ ] 部门复盘（亮点与不足、下次改进点）
- [ ] 物料归档（通知/海报/照片/签到表归入宣传部对应分类）
- [ ] 沉淀后续活动意向（咨询群保留，收集下一期需求）
