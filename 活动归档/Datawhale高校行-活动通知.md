# 活动通知：DataWhale AI+X 高校行——哈工大场（《AI 新手村》系列）

> 来源：宣传部 02-活动方案，2026-10
> 【"智启新航"AI研学社｜DataWhale AI+X 高校行——哈工大场活动通知】

哈工大"智启新航"AI研学社联合 DataWhale AI+X 高校行，面向全体在校师生开展 AI+X 高校行第八期《AI 新手村》系列活动。

## 活动内容

技术部员分享 + Agent 搭建演示 + 动手实践任务，借助学校和 DataWhale 提供的相关教学资源，帮你从零开始完成一个高频场景的 AI 小作品，并了解 AI 通识概念。

教学内容涵盖：

- AI 通识
- Agent 使用入门
- GitHub 注册与使用
- 利用 Agent 创建仓库 + 生成 README
- 解报错等知识与技能

## 参加活动你将获得

- DataWhale 颁发的活动证书
- 在和行业前辈、学哥学姐、在场同学的交流中了解真实经验、收获同行伙伴
- 了解 AI 通识概念地图，掌握一个高频场景 AI 实用技能，明确自己在 AI 学习路径上的下一步
- 开发和提交一个 AI 小作品，获得周边好礼
