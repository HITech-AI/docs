# 第一场活动：开源第一课 · GitHub 与 AI Agent 入门（融合 Datawhale《AI 新手村》）

> 来源：技术部 02-活动方案，2026-10
> 定位：**对外公开**的 AI 入门实践活动
> 载体：Datawhale AI+X 高校行第八期《AI 新手村》为主载体
> 主题特色：GitHub + AI Agent 入门
> 形式：线下实操工作坊 + 线上腾讯会议同步
> 面向对象：全校新生 / 零基础同学（公开开放）
> 建议时长：150 分钟（2.5 小时，按新手村流程）

## 一、活动定位

第一场活动以 **Datawhale《AI 新手村》** 为组织载体，做一场**对外公开**的 AI 入门实践：学生在现场完成一个高频场景的 AI 小作品，并了解 AI 通识概念。同时在活动主题上**保留本社特色——GitHub 与 AI Agent**，把"用 AI Agent 完成一次开源协作"作为动手实践的主要落点。

- 由 Datawhale 提供教程、SOP、物料与嘉宾支持；学校提供场地与组织人员。
- 活动不代言任何 AI 产品，学生自选工具完成同一任务并对工具打分评价。
- 完成者可获 Datawhale 证书 + 周边，并可免费学习 36 门 AI 入门课。

## 二、活动目标

1. **面向全校的 AI 入门科普**：让零基础同学认识 AI、会用 Agent，做出第一个 AI 作品；
2. **掌握 GitHub 基本操作**：注册、仓库、commit/push、Issue 与 PR；
3. **会用 AI Agent 当 GitHub 助手**：答疑、生成文档、写提交、解报错、生成 PR；
4. **打通闭环**：用 Agent 辅助完成一次完整的 GitHub 协作 / 开源贡献；
5. **扩大社团影响力**：对外招新引流，沉淀为可复用的活动案例。

## 五、认识 AI 与 Agent（分享环节支撑内容）

### （一）AI 的能力范围
| 能力 | 说明 |
|---|---|
| 对话与问答 | 答疑、讲解、头脑风暴 |
| 写作与翻译 | 文案、总结、多语言翻译 |
| 编程 | 生成 / 解释 / 调试代码 |
| 创作 | 绘图、视频、音频生成 |
| 办公 | 文档、PPT、表格制作 |
| 学习辅助 | 讲解知识、出题、复习规划 |
| 智能体（Agent） | 规划任务、调用工具、自主完成 |

### （二）Agent 与 AI 的区别
| 维度 | AI（模型） | Agent（智能体） |
|---|---|---|
| 本质 | 生成与理解能力 | 能自主执行任务的助手 |
| 主动性 | 被动，等你提问 | 主动规划、多步执行 |
| 工具调用 | 通常不直接调用 | 可调用搜索、代码、文件等工具 |
| 任务 | 单次问答 | 拆解目标、完成任务闭环 |
| 比喻 | 会思考的大脑 | 会干活的助手（有手有脚） |

### （三）核心思路：Agent 是贯穿 GitHub 每一步的助手
| GitHub 环节 | AI Agent 辅助点 |
|---|---|
| 注册 / 认识界面 | 用 Agent 提问"GitHub 是什么、这个界面怎么用" |
| 创建仓库 | 用 Agent 生成仓库介绍（README） |
| commit / push | 让 Agent 写规范提交说明；报错直接丢给 Agent 问 |
| Issue / PR | 用 Agent 生成 Issue/PR 描述；Agent 帮 review 代码 |

## 六、现场小任务：你的第一份 AI 作品与开源贡献

**任务目标**：完成一个 AI 小作品（新手村 demo）+ 走一遍"Agent 辅助完成一次 GitHub 协作"的闭环。

**任务步骤**：
1. 用 Agent 想一个主题（个人主页 / AI 学习笔记 / 感兴趣的小项目）
2. 用 Agent 生成作品内容与仓库 README
3. 创建仓库，用 Agent 辅助完成 commit / push
4. 用 Agent 写 PR 说明，发起一次 Pull Request
5. 社团开源组织已建立，PR 提到组织仓库；未建则提交到个人仓库留档

**验收**：将作品 / 仓库 / PR 链接登记到部门台账，作为活动成果留档；同时按新手村要求提交作品库。

**激励**：完成任务者获 Datawhale 证书 + 周边，并登记为社团开源组织首批贡献者。
